# 🚢 Titanic Data Analysis

## 📌 Project Overview

This project performs exploratory data analysis (EDA) on the Titanic dataset to understand the factors that influenced passenger survival.

The analysis includes data cleaning, exploration, visualization, and identification of important patterns related to passenger survival.

## 🎯 Objectives

- Analyze the Titanic passenger dataset
- Clean and preprocess the data
- Explore passenger demographics and survival patterns
- Analyze the impact of gender, age, passenger class, and fare on survival
- Create meaningful visualizations
- Extract useful insights from the data

## 🛠️ Technologies & Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis

The project explores:

- Survival rate of passengers
- Survival based on gender
- Survival based on passenger class
- Age distribution of passengers
- Relationship between fare and survival
- Passenger class and gender comparisons

## 📁 Project Files

- `Titanic-data-analysis.ipynb` — Jupyter Notebook containing the complete analysis
- `Titanic-Data.csv` — Dataset used for the analysis

## 🔍 Key Insights

The analysis helps identify important patterns in passenger survival and demonstrates how data analysis and visualization can be used to extract meaningful insights from real-world datasets.

## 🚀 How to Run

1. Clone this repository.
2. Open `Titanic-data-analysis.ipynb` in Jupyter Notebook or Google Colab.
3. Make sure the dataset is available in the same directory.
4. Run the notebook cells sequentially.
